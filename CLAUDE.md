# Number Guessing Game

## Project Overview
Build a number guessing game where the player guesses a randomly generated number between 1 and 100.

## Game Logic
- Generate a random number between 1 and 100.
- Give the player 5 attempts.
- Allow the player to enter a number.
- Tell the player whether their guess is too high or too low.
- Display the remaining attempts.
- Show a winning message if the player guesses correctly.
- Show a losing message if all attempts are used.
- Allow the player to restart the game.
